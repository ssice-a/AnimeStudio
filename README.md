# AnimeStudio

This EFF fork provides resource browsing, unpacking and source-package export. Download its independent release from [AnimeStudio Releases](https://github.com/ssice-a/AnimeStudio/releases).

Current EFF workflow, index storage and shared-tool locations are documented in the [EFF main repository](https://github.com/ssice-a/EFF), especially [Shared Tools and Indexes](https://github.com/ssice-a/EFF/blob/main/docs/shared-tools-and-indexes.md) and the [Mod tutorial](https://github.com/ssice-a/EFF/blob/main/Mod%20Tutorial.md).

Keep the index workspace at the location you choose. AnimeStudio registers its path for Blender and EFF Mod Manager; it does not copy the full index into either application.
